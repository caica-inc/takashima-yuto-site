# 関東建設マネジメント（KCM）デザインフォーマット 第1.0版

会社案内パンフレット2026（クロノスケ制作・カイカディレクション）の実データから
色をピクセル単位で抽出して策定した、KCM向け資料の標準様式。
テンプレート本体は `KCMデザインフォーマット.pptx`。

## カラーパレット

| 名称 | HEX | 用途 |
|---|---|---|
| KCMブルー | `#045292` | メイン。見出し・罫線・チップ文字・図の主要素 |
| KCMライム | `#B6D55E` | アクセント。フッター斜線帯・画像フレーム上辺 |
| マーカー | `#E3EA61` | 見出し・キーメッセージの蛍光マーカー風ハイライト |
| ライトブルー | `#9CD9F0` | 番号チップ（Qバッジ）・小見出し下地 |
| ペールブルー | `#D9E9F8` | 表ヘッダー・データ行の帯 |
| ピンク | `#F2B3C1` | サブアクセント（第2系統の色分け） |
| 本文 | `#1C2430` / 補足 `#5A6472` | 文字色。背景は白 |

## デザインモチーフ（会社案内より）

- 白背景 + 角丸カード。カードは背景色 `#F5F8FA` で区切り、枠線を使わない
- 見出しは「英語ラベル（青・字間広め・Arial）＋日本語見出し（マーカー強調）」の2段組
- ページ下部にライムの斜線ストライプ帯（全ページ共通のフッター）
- 番号は「Qバッジ」風のライトブルー角丸チップ + 青文字
- 写真・図版は角丸 + 上辺ライムのアクセント

## 書体

- 見出し: Meiryo UI 太字（印刷物は游ゴシック Medium）
- 本文: Meiryo UI 12〜14pt、補足 10.5pt
- 英語ラベル・数字・コード: Arial
