SEKISAN SUPPORT TOOL

積算の帳票づくりを、
読み込むだけに。

新土木工事積算システムの「入力データリスト」をブラウザに読み込むだけで、設計積算条件リスト・数量総括表などの帳票を自動作成。Acrobat・DocuWorks・Excelマクロは必要ありません。インストール不要、データは端末内だけで処理されます。

BEFORE / AFTER
従来PDF印刷 ▶ Acrobat 11でExcel変換 ▶ 編集マクロ ▶ 帳票マクロ ▶ 目視確認・手入力
本ツールPDF印刷 ▶ ブラウザに読み込む ▶ 画面で確認・入力(残件表示) ▶ Excel一括出力
HOW IT WORKS

使い方は3ステップ

STEP 1読み込む新土積システムから「鏡なし・STまで」で印刷したPDFをドラッグ＆ドロップ
STEP 2確認・入力する色付き箇所をプルダウンで確認・入力。要対応の残件数を自動表示、0件で完了
STEP 3Excelを出力する4帳票入りのExcelを一括ダウンロード。画面での入力も反映済み
PROBLEM

こんなお困りごとを解決します

1変換が不安定Acrobatのバージョン差やDocuWorks変換でレイアウトが崩れ、ツールが動かない
2マクロ配布が大変セキュリティ警告や更新配布の管理が全支店展開のハードルに
3確認が目視頼み色付きセルを目で探して手入力。確認漏れに気づきにくい
FEATURES

4つの特長

APDFを直接読み込み変換ソフト不要。Acrobat変換済みExcelやテキスト貼り付けにも対応(従来フロー互換)
B残件を自動カウント市場単価の夜間確認・独自歩掛の入力・単位不一致などを数えて一覧表示。クリックで該当行へ
C途中保存・引き継ぎ入力は自動保存。作業ファイル(.json)で別PC・別担当者への引き継ぎも可能
D納品物はExcel旧システム(Ver2.2.2)の様式・色分け・プルダウンを踏襲。既存の照査・提出フローにそのまま載る
REPORTS

出力される帳票

① 設計積算条件リスト　内容・根拠又は理由を自動入力。夜間○は一括割増率50%で自動判定
② 数量総括表　工事区分〜細別の階層と規格・数量を自動転記。変更工事の列構成にも対応
③ 交通誘導員集計　交通誘導警備員の計上箇所を工種別に一覧化
④ チェック結果　単位・単位数量の不一致などの自動チェック一覧。照査記録にも
SECURITY

データは端末の中だけで処理

外部送信なし積算データはブラウザ内でのみ処理。外部サーバーへは一切送信されません
置くだけで展開社内サーバーやSharePointに配置するだけで全支店から利用可。オフライン動作可
動作環境　Microsoft Edge / Google Chrome（最新版推奨）。インストール不要。
