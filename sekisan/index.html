KCM積算ツール（積算業務支援）

新土木工事積算システムの「入力データリスト」から、設計積算条件リスト・数量総括表などの帳票を自動作成。確認・入力作業はブラウザ上で行い、最終帳票をExcelで出力します。データはすべて端末内で処理され、外部に送信されません。

1. 読み込む

PDF / Excel（.xlsx / .xlsm）／ 作業ファイル（.json）をここにドラッグ＆ドロップ
またはクリックして選択

・新土積システムから「鏡ページ無し・STまで」で印刷したPDFをそのまま読み込めます（Acrobat・DocuWorksでの変換は不要です）。
・Acrobat等でExcel変換済みのファイル、コピー＆ペーストのテキスト、保存した作業ファイル(.json)にも対応しています。

3. 設計積算条件リストの確認・入力 残 0 件

色付きの箇所を確認・入力してください。項目をクリックすると該当行へ移動します。入力内容は自動保存され、Excel出力にも反映されます。

    市場単価（夜間○/－を選択） 単位・単位数量の不一致（確認済チェック） 独自歩掛かり（設計の考え方を入力） 処分費（出典を入力）
    種別夜間○単位数量単位数量数量(変更) 内容根拠又は理由設計の考え方及び措置摘要基準書コード確認

    このツールについて

    作成フロー（旧システムとの違い）
    【旧】新土積システム → 入力データリスト印刷(PDF) → Acrobat 11でExcel変換 → 入力データリスト編集システム(マクロ) → 各帳票マクロで作成 → Excel上で目視確認・手入力
    【新】新土積システム → 入力データリスト印刷(PDF) → このページに読み込む → ブラウザ上で確認・入力（残件数を自動表示） → 最終帳票をExcel出力

    Acrobatのバージョン依存・DocuWorks変換でのレイアウト崩れ（2022〜2023年に検証された課題）を、PDFを直接解析することで回避しています。
    出力される帳票
    ① 設計積算条件リスト … 内容・根拠又は理由を自動入力し、ブラウザでの修正を反映。夜間○は一括割増率50%で自動判定。色分け・プルダウンは旧Ver2.2.2の様式を踏襲。
    ② 数量総括表 … 工事区分〜細別の階層と規格・数量を自動転記。
    ③ 交通誘導員集計 … 交通誘導警備員の計上箇所を一覧化。
    ④ チェック結果 … 単位不一致・単位数量不一致などの自動チェック一覧。
