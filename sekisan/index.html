KCM積算ツール（積算業務支援）

新土木工事積算システムの「入力データリスト」から、設計積算条件リスト・数量総括表などの帳票を自動作成します。データはすべてブラウザ内で処理され、外部に送信されません。

1. 入力データリストを読み込む

PDF / Excel（.xlsx / .xlsm）ファイルをここにドラッグ＆ドロップ
またはクリックして選択

・新土積システムから「鏡ページ無し・STまで」で印刷したPDFをそのまま読み込めます（Acrobat・DocuWorksでの変換は不要です）。
・Acrobat等でExcel変換済みのファイル、コピー＆ペーストのテキストにも対応しています。

テキストを貼り付けて読み込む

2. 解析結果の確認

自動チェック（0件）

    市場単価（夜間の有無を確認） 単位・単位数量の不一致 独自歩掛かり 登録材料・処分費

    このツールについて

    作成フロー（旧システムとの違い）
    【旧】新土積システム → 入力データリスト印刷(PDF) → Acrobat 11でExcel変換 → 入力データリスト編集システム(マクロ) → 各帳票マクロで作成
    【新】新土積システム → 入力データリスト印刷(PDF) → このページに読み込むだけ → 帳票を一括出力

    Acrobatのバージョン依存・DocuWorks変換でのレイアウト崩れ（2022〜2023年に近江さん・矢野さんが検証した課題）を、 PDFを直接解析することで回避しています。
    出力される帳票
    ① 設計積算条件リスト … 内容・根拠又は理由を自動入力（「積算基準書(赤本)どおり」「独自歩掛」「材料単価」等）。夜間○は一括割増率50%で自動判定。プルダウン・色分けは旧Ver2.2.2の様式を踏襲。
    ② 数量総括表 … 工事区分〜細別の階層と規格・数量を自動転記。変更工事は当初/変更/増減の列構成。
    ③ 交通誘導員集計 … 交通誘導警備員の計上箇所を一覧化。
    ④ チェック結果 … 単位不一致・単位数量不一致などの自動チェック一覧。
