# KCM積算ツール（積算業務支援）

新土木工事積算システム（新土積システム）が出力する**入力データリスト**から、
**設計積算条件リスト・数量総括表・交通誘導員集計・自動チェック結果**の各帳票を
自動作成するブラウザ完結型ツール。

関東建設マネジメント株式会社（KCM）企画部・小山和行氏からの相談を起点に、
完成に至っていなかった「積算ツール」を形にしたもの。

**未完成の根本原因**＝入力データリストの取り込みが Acrobat 11 / DocuWorks という
外部ソフトのバージョン・挙動に依存していたこと。

## 本ツールのアプローチ

```
【旧】新土積システム → PDF印刷 → Acrobat11でExcel変換 → 編集システム(マクロ) → 各帳票マクロ
【新】新土積システム → PDF印刷 → このツールに読み込むだけ → 帳票を一括出力
```

- PDFをブラウザ内で直接解析（pdf.js）。**Acrobat・DocuWorksへの依存を撤廃**
- Acrobat変換済みExcel（.xlsx/.xlsm）やテキスト貼り付けにも対応（既存フローとの互換）
- 帳票はExcelJSで生成。**旧Ver2.2.2の様式・色分け・プルダウンを踏襲**
  - オレンジ＝市場単価（WB7〜/WB8〜）、赤＝単位・単位数量の不一致、青＝独自歩掛かり、ピンク＝登録材料・処分費
  - 夜間○は一括割増率50%で自動判定
  - 根拠又は理由は「積算基準書(赤本)どおり」「独自歩掛」等を自動入力
- **データはすべて端末内で処理**され、外部サーバーに送信されない（官公庁積算データの取り扱いを考慮）

## ファイル構成

```
sekisan/
  index.html      … アプリ本体（開くだけで動作。サーバー不要）
  js/parser.js    … 入力データリスト解析（階層・単価表・Q/J条件・摘要メタの抽出）
  js/generator.js … 帳票生成（設計積算条件リスト／数量総括表／誘導員集計／チェック結果）
  js/app.js       … UI・PDF/Excel読み込み
  vendor/         … ExcelJS 4.4.0 / pdf.js 3.11.174（同梱・オフライン動作可）
```
