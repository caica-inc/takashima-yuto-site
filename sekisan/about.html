PROBLEM

こんなお困りごとありませんか

1

変換が不安定

AcrobatのバージョンやDocuWorks経由の変換でレイアウトが崩れ、Excelツールが動かない。

2

マクロの配布が大変

Excelマクロはセキュリティ警告や更新配布の管理が必要で、支店展開のハードルに。

3

確認作業が目視頼み

色付きセルを目で探して手入力。確認漏れ・入力漏れに気づきにくい。

FEATURES

KCM積算ツールの4つの特長

A

PDFを直接読み込み

「鏡なし・STまで」で印刷したPDFをドラッグ＆ドロップするだけ。変換ソフトは不要です。

B

残件を自動カウント

市場単価の夜間確認・独自歩掛の入力などの要対応箇所を数えて表示。0件になれば完了です。

C

途中保存・引き継ぎ

入力は自動保存。作業ファイル(.json)で別PC・別担当者への引き継ぎもできます。

D

納品物はExcel

最終帳票は従来どおりのExcel様式(旧Ver2.2.2踏襲)。既存の照査・提出フローにそのまま載ります。

HOW IT WORKS

使い方は3ステップ

読み込む新土積システムから印刷した入力データリスト(PDF)をドラッグ＆ドロップ
確認・入力する色付き箇所をプルダウンとセル入力で確認。残件数が0になれば完了
Excelを出力する4帳票入りのExcelを一括ダウンロード。画面の入力内容も反映済み
REPORTS

出力される帳票

設計積算条件リスト内容・根拠を自動入力。色分け・プルダウン付き
数量総括表工事区分〜細別の階層と規格・数量を自動転記
交通誘導員集計交通誘導警備員の計上箇所を一覧化
チェック結果単位・単位数量の不一致などを自動検出
SECURITY

データは端末の中だけで処理

読み込んだ積算データはブラウザ内でのみ処理され、外部のサーバーには一切送信されません。インストール不要・オフライン動作可。社内サーバーやSharePointに置くだけで全支店から利用できます。

動作環境: Microsoft Edge / Google Chrome（最新版推奨）
