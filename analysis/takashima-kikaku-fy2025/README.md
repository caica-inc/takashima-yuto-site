## 3. クレジットカードからのアパレル関連抽出

依頼のあった「カイカと同じカードでの企画関連購入」の抽出結果:

- **AMEX本体(下4桁1003/3004/1005/3009等)**: メール通知は週次利用合計のみで加盟店別明細が存在しないため、メールからの店舗別抽出は不可。正確な抽出にはAMEXオンライン明細(CSV)が必要。
- **エムアイカードプラスG AMEX**: 利用通知メールが存在する2026/5/21〜7/11分のみ抽出可能。全14件・**¥555,468**、すべて伊勢丹新宿店・三越伊勢丹オンラインストア等の百貨店利用(アパレル購入の可能性が高いが、事業仕入か個人利用かは要判別)。明細は data/micard_transactions.csv。
- **メール注文履歴からのアパレル購入**(data/sales_and_purchases.csv、約49件):
  - 事業仕入として最有力: **オリジナルプリント.jp Tシャツプリント発注 17枚 ¥80,599(2026/7/7、代行出荷指定)** — 販売再開(7月のShopifyペイメント有効化)と時期が一致
  - ZOZOTOWN: COMME des GARCONS HOMME Tシャツ5点 計約¥147,000(2026/7)
  - メルカリ/メルカリShops: mame kurogouchi・PLEATS PLEASE・Margiela等 多数(個人利用の色彩が強い)
  - SHEIN/AliExpress/Alibaba/OEM等の海外仕入メールは期間内ゼロ(仕入はFabシートの「倉庫/仕入費用」として月24〜40万円計上されており、別ルート・別アカウントで発注されている可能性)
